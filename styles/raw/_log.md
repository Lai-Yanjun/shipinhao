### 三个和原计划不一样的地方

#### 1. curl / yt-dlp 没走通

bilibili.com 被本次会话的出网白名单拦截，CONNECT 返回 403。
云端容器和本机 shell 走同一套代理策略，所以「本机网络是通的」这个前提不成立。
`scripts/fetch_transcript.py` 这次一行都没用上。

实际路径：通过本机 Chrome 的登录态直接调 B 站 Web API。

1. `x/space/wbi/arc/search?mid=<uid>&order=click` 取投稿列表，按 `play` 降序取前 5
2. `x/player/pagelist` 取 cid → `x/player/wbi/v2` 取字幕列表 → fetch `subtitle_url`
3. 字幕 JSON 自带 `from`/`to` 时间戳，所以 90 秒切点和「最后 15 秒」都是准的

#### 2. 别信 space 页面的排序

`space.bilibili.com/<uid>/video?order=click` 这个页面实测**没有**真的按播放量排序，
DOM 顺序是乱的（第一条 77万 排在 769万 前面）。榜单要走 API 的 `play` 字段自己排。
wbi 签名是必须的，不签名直接返回 -799。

#### 3. 中段没抓

按 `_template.md` 的要求：「不用抄中段，十分钟口播的展开部分对 30 秒静态页没用」。
所以每个文件只有钩子段（前 60-90 秒，整理成信息骨架）和结尾（最后 15 秒）。
需要中段的话按 BV 号单独补。

### 字幕质量提醒

B 站 AI 字幕**无标点**，换行即语流停顿单位 —— 这对分析口播节奏反而是好事，
每行就是一个自然气口。骨架整理时我按这个断行，再合并了明显属于同一句的碎行。

错字不少，尤其是专名。我在整理骨架时改掉了能确认的，列在这里：

- 「鳌太线」字幕作「敖泰县 / 敖台县 / 熬泰 / 鳌胎 / 鳌台县」——已改
- UP 主自称「神秘园」字幕作「神明安 / 神明妍 / 神明啊」——已改
- 「尼卡杰克」字幕作「尼卡捷克 / 尼卡尔杰克」混用——已统一
- 「廿日市」字幕作「念日逝世 / 念日试试 / 念人世事」——已改
