# 写作规则（蒸馏结果）

语料：两个对标账号各 5 条高播放视频的开头段，见 `styles/raw/`。
拆取与字幕勘误记录见 `styles/raw/_log.md`。

**只提炼规则，不保留原句。** 下面所有示例均用本栏目题材重写，不是样本原文。

---

## 零、长度校准（先看这条，它决定其他所有条）

对标账号一条 10-29 分钟，取的 90 秒只是它的开胃菜，后面有的是时间铺垫。

**我们整条 30 秒。正确的类比是：本栏目的 8 页 ≈ 他们的 90 秒钩子段，
不是他们的整条视频。**

推论，全部是硬约束：

1. **不允许存在铺垫页。** 每一页都必须自带钩子。哪怕是坐标页。
2. **不要摊时间轴。** 他们能用十分钟走完"第一天…第三天…二十六天后"，
   我们摊开就是把六个爆点稀释成三十行。时间信息压进正文，不占页。
3. **页标题必须是钩子句** —— 不是时间戳，不是内容小标题。
   - 好：`十个人出发，九个人到达` `帐篷是从里面割开的` `雪地上没有第十组脚印`
   - 差：`二十六天后` `五月，雪化了`（时间戳，不带信息）
   - 差：`营地现场` `尸检记录`（小标题，零张力）
4. **每页正文的最后一行必须加压**，不能落在陈述上。
5. 页标题控制在 12 字以内，超了会折成三行吃掉版面。

对照组：用户给的原始参考案例是**一页六行，六行全是爆点，零铺垫**。
我们做八页，就得有八倍的爆点，而不是把同样的内容摊薄八倍。

## 一、冷开场：第一句就是事件本身

十条样本在这一点上分成了两派，差别极其明显：

- **户外类 5/5 冷开场**：第一句直接是事件，自报家门推到钩子中段甚至整条都不出现
- **悬案类 5/5 热开场**：「大家好我是某某，欢迎来到某某」起手，接一段地理或人物科普

两派播放量差一个数量级，但**不能据此断言是开场造成的** —— 题材、更新时间、账号体量
都是混杂因素，样本量也不足以支持因果结论。

但对我们的判断是确定的：**30 秒静态图文里，热开场的前 5 秒全废。**
我们没有主播人格，没有"欢迎来到"的位置，第一页必须是事件本身。

## 二、两种钩子结构，按素材选

### A. 未完成的故事（户外类的做法）

讲一个正在发生、结局不给的事件，靠时间推进拉着人往下走。

```
有人做了一件反常的事 → 出了什么岔子 → 结局不给
```

适合：有清晰时间轴的事故、失踪、远征。

**注意**：借它的因果链，不要借它的节奏。时间标记压进正文里的一行，
不要拿去做页标题 —— 见第零条第 3 点。

### B. 立共识，再推翻（悬案类里写得最好的一条的做法）

```
所有人都以为是 X → 但最近出现了新的东西 → 它指向 Y
```

适合：结论被改写过、有新证据、或官方说法与现场矛盾的选题。

**这个结构不依赖时间轴，一张静态页就能承载完整张力** —— 上半是共识，下半是裂缝。
对我们比 A 更省版面。选题只要有"官方说法变过"这一条，优先用 B。

两种可以叠：主干走 A，contradiction 页用 B 的句式。

## 三、钩子加压手法

样本里反复出现、且能迁移到静态页的：

| 手法 | 做法 | 本栏目写法示例 |
|---|---|---|
| 死因写成动作 | 不写"遇难"，写他当时在做什么 | `他追着那道光越走越远` |
| 荒谬数字对比 | 用数字自己暴露荒谬，不加形容词 | `一百多名搜救人员，没有一个到过那条沟` |
| 术语变化 | 用一个词的替换暗示状态逆转 | `行动从搜救改为打捞` |
| 日常算术出错 | 清点时少一个人，比任何惊悚描写都吓人 | `上岸清点时，少了一个` |
| 精确数字做支点 | 先铺模糊时长，再给一个精确天数 | `找了近一个月 … 直到第 27 天` |
| 密度数字升格 | 把个案变成系统性危险 | `五年之内，这条线上有四十六人没有下来` |
| 机器记录承诺 | 预告有观众看不到但设备记下的实锤 | `他的潜水电脑记下了那段时间` |
| 双线并置 | 一个钩子装两个未完成的命运 | `同一时刻，另一个人正坐在半山腰` |
| 新鲜度改预期 | 抢在"又是老案子"之前改判断 | `这不是陈年旧案` |
| 素材两用 | 背景既加恐怖属性又埋地理伏笔 | 麻风病隔离洞式的设定 |
| 预装地图 | 先给几何结构，后面剧情才看得懂 | `通道在八米处分叉，十二米交汇` |

每页至少用上一种。**不要连用三种以上** —— 样本里最好的段落都很克制。

## 四、反面教材：这五件事不要做

全部来自悬案类样本的实际写法，它们靠题材红利撑住了播放量，不是靠文案：

1. **自报家门开场**。我们没有主播，这一条天然不存在，但引申是：
   第一页不许出现任何"本栏目""本期"之类的自我指涉。
2. **通用议论开场**。"探险都有不确定性、都有风险" —— 十句不带任何具体信息。
   静态图文里这种句子一句都不能要。
3. **背景科普占据钩子位置**。有一条把全片最有记忆点的地名词源放在第 60-75 秒，
   位置浪费了。好东西要前置。
4. **标题承诺了却不兑现**。标题写"因一件不起眼的事告破"，开头不复述那是什么；
   标题写"密室失踪"，钩子只讲"联系不上"。**我们的封面钩子必须在 P2-P3 内兑现。**
5. **说得平、不加压**。提到"被卡住"之后直接报案件名，不追问。
   户外类的做法是追一句"他真的已经死了吗"。

## 五、人物小传是情绪储蓄

有一条把人物写得比案情还细（性格、父亲、妻子、十三个月大的女儿），
这是提前把"可惜"存进去，好让结尾取出来。结尾确实取出来了。

我们的 P2 可以存一笔 —— 一个具体身份或一个具体牵挂，**一行就够**，
然后在 P8 取出来。不要展开成小传，版面不允许。

## 六、版面预算（硬约束）

| 项 | 上限 | 超出后果 |
|---|---|---|
| 每页正文行数 | 5 行 | 图注与页脚被挤出页面 |
| 每行字数 | 18 字 | 折行，同上 |

`pipeline/verify.py` 会机器检查，超一个字就卡住。写之前先数。

## 七、句长节奏

```
长句（15-18字）   铺垫
中句（10-14字）   推进
短句（4-7字）     转折 ← 独占一行
中句（10-14字）   落地
```

转折点必须是短句且独立成行。页标题本身就可以是这个短句（`而奇怪的是` `二十六天后`）。

## 八、禁用词

`震惊` `细思极恐` `毛骨悚然` `不寒而栗` `骇人听闻` `真相竟然`

样本里一个都没出现。这类词是替观众下情绪结论，反而暴露内容不够硬。
**只给事实，情绪由观众自己产生。** 已进 `verify.py` 的机器检查。

## 九、结尾

按案件状态选，不要混：

| 状态 | 收法 | 样本里的效果 |
|---|---|---|
| 已结案 | 闭合，呼应封面钩子 | 稳，但不留讨论 |
| 未结案 | 开放 + 呼吁 | 自然，能带评论 |
| 结论被改写过 | `还不能下定论，但离答案从没这么近过` | 最好的一种 |
| 有安全教训 | 对仗警告 | `成功了罚款，失败了留在上面`式 |

对仗句是全样本里唯一能直接搬进静态图文的句式 —— 它天生是两行。

cta 页可以叠：先给收尾句，再预告下期（**预告也要延迟命名**）。

## 十、封面与命名

**封面是主标题 + 副标题的双层结构：**

- **主标题** = 正式的事件命名（`迪亚特洛夫事件`）—— 给可信度与档案感
- **副标题** = 拉人的钩子句（`赤脚逃出帐篷`）—— 给点击率

两者都要。只有正式名没人点，只有钩子句像标题党。

内页仍然延迟命名：能推迟到第 3 页之后再提事件学名就推迟。
- 下期预告：写`三十三年后被冲洗出来的底片`，不写`安德烈北极气球远征`

## 迁移边界

样本是 10-29 分钟口播，本栏目是 30 秒静态页、无旁白。

- **迁移**：上述全部结构与加压手法
- **不迁移**：口语连接词、主播人格、固定收尾口播、语速 ——
  页面上没有声音，这些照搬全是废话

样本的语速在 234-344 字/分钟之间，与播放量看不出关系，对我们也没有参照价值。

## 样本回答不了的问题

- **封面文字没抓**（10/10 缺）。我们的封面钩子是整条流水线上最关键的一环，
  却没有任何对标样本。这是当前最大的缺口。
- 冷开场与播放量的因果关系无法证明，混杂因素太多。
- 只有开头段和结尾，中段未取。展开部分的节奏无从判断，但对 30 秒图文影响不大。
