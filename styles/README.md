# 风格锚定语料

放你认为优秀的博主文案，用于蒸馏写作规则。

## 怎么放

每条一个文件 `styles/raw/<任意名>.md`，文字誊录即可，不需要视频。附上你觉得它好在哪。

## 怎么用

拆解结果写进 `styles/rules.md`，生成文案时作为硬约束遵循。

**只提炼规则，不保留原句。** 学结构与节奏合法且有效；抄句子会被平台查重判搬运。

拆解维度：
- 钩子类型（动作反常 / 数字反差 / 身份错位 / 时间跨度）
- 句长节奏曲线（哪句长、哪句短、在哪断）
- 信息密度（每句携带几个新信息点）
- 悬念投放位置（第几句制造逻辑空洞）
- 结尾处理（留白 / 反问 / 预告）
