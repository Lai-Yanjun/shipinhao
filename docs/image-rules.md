# 选图规则

## 零、顺序：图注跟着图走，不是图跟着图注走

**先挑图，再写图注。**

原先的顺序是写文案时连图注一起写死，再去找能匹配那句话的图。
这会逼着人在「找不到匹配的图」时做两件坏事之一：凑一张不相干的，或者改图注去迁就。
实测踩过：图注写「出发前的队伍合影，1959年1月」，配的却是 2012 年的纪念碑。

改成先选图、后回填图注之后，吸引力和真实性就不冲突了 ——
图注永远描述图里实际有什么，只是「描述哪一张」由吸引力决定。

所以 `script.json` 初稿的 `image_caption` 留空，`image_query` 照写。
配图定稿后再回填图注。

## 一、优先级阶梯

从高往低挑，**每一级都挑不到才降级**：

| 级 | 类型 | 说明 |
|---|---|---|
| 1 | **现场照，画面里有人在活动** | 观众最想看的是「当时是什么样」。有人、有动作、有现场，三者齐了就是最强的一张 |
| 2 | **现场照，无人但有实物** | 帐篷、装备、遗留物。仍然是「当时」 |
| 3 | 同一事件的其他时刻或其他角度 | 搜救过程、出发前、事后勘查 |
| 4 | 同一地点的历史影像 | 年代对得上，地点对得上，事件不直接相关 |
| 5 | 同一地区的年代风景 | 泛化了，但仍是真实的历史影像 |
| 6 | 地图、示意图、剖面图 | 信息量高但没有情绪。兜底，别当主力 |
| 7 | **不配图** | 渲染成虚线占位框。**宁可空着，不要错的** |

第 7 级是正经选项，不是失败。一页空着损失的是观感，配错一张损失的是可信度，
而这个栏目全部的说服力都建立在可信度上。

## 二、一票否决

命中任意一条就换图，不看它多好看：

- **后人拍的纪念性影像** —— 纪念碑、墓碑、周年活动、后人重访。
  它们看着高度相关，实际把观众从「1959年的那个夜晚」拽回「某年的某个下午」，
  当场毁掉沉浸感。这是最容易犯、也最难自查的一条
- **可辨认的遇难者遗体** —— 合规红线，也是平台审核红线
- **画面里有现代元素** —— 汽车、路标、游客、现代服装。破坏年代感
- **文书扫描件当主图** —— 授权干净但观众看不清也看不懂
  （`assets_search.looks_like_photo` 已自动剔除）

## 三、模板带来的硬约束

图会被 `object-fit: cover` 裁成约 1080×620，再叠 `grayscale(0.35) contrast(1.06)`。

- **主体必须在画面中央的横带上。** 竖图进来上下会被裁掉大半，
  主体在上三分之一或下三分之一的，裁完就没了
- **横图优先。** 原图宽高比低于 1.2 会损失三成以上画面，低于 0.87 损失过半
- **原图至少 1080×620**，低于这个数满幅铺开会糊
- **原图对比度别太平。** 还要再叠一层去色，本来就灰的图会糊成一片
- **封面图另有要求**：会被 sepia 做旧 + 白边 + 轻微旋转，太暗的图处理完是一团黑

分辨率与裁切损失已进 `pipeline/verify.py` 的机器检查，超标会卡住。

## 四、一期之内的序列

八页的图放在一起要能构成序列，不要八张同一个机位。

粗略配比：现场照 3-4 张、地形或环境 1-2 张、地图 1 张、空 1-2 页。
全是现场照会腻，全是地图会闷。

## 五、这条规则不会自动生效

优先级阶梯里除了「不配图」和尺寸，其余全是人的判断 ——
机器分不清一张雪地照是 1959 年的搜救现场还是 2012 年的纪念活动。

所以 `cli.py assets` 出的九宫格是让你按这份规则**逐张过眼**的，
不是让你点最上面那张。
