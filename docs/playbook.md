# 内容方法论

> **修订说明**：`styles/rules.md` 是从对标样本蒸馏出的细则，与本文冲突时以它为准。
> 它补上了本文最初漏掉的三件事：安全铺垫、信息落差、时间推进优先于分类罗列。

## 一、六段式递进

每一期都必须走完这六步，顺序不能换。这是从对标账号拆出来的结构：

| 步骤 | 内容 | 作用 |
|---|---|---|
| 1 坐标 | 时间 + 地点 | 建立真实感 |
| 2 反常行为 | 当事人做了一件不合常理的**具体动作** | 钩子 |
| 3 结局下沉 | 最后怎么了 | 交代结果 |
| 4 诡异峰值 | 最反直觉的一个**记录在案**的细节 | 拉满好奇 |
| 5 逻辑空洞 | 一个把所有常规解释都堵死的矛盾点 | **整条的命门** |
| 6 权威悬置 | 官方结论是什么、何时给出、还有什么没解释 | 留白收尾 |

第 5 步是关键。前四步给了一堆异常，第 5 步把凶杀、袭击、事故这些常规解释全部堵死，
观众的大脑被迫停在「那到底是什么」——这才是完播与评论的真正来源。
模板里给逻辑空洞页的最后一行加了颜色重音，就是为了强调这一行。

## 二、封面钩子

**绝不使用事件学名。**「迪亚特洛夫事件」观众不认识，不会点；
「赤脚逃出帐篷」任何人都懂，而且立刻反常。

写法：具体动作 + 反常，5-8 个汉字。

好：赤脚逃出帐篷 / 底片冲洗出最后一夜 / 他给自己做了手术
差：乌拉尔山惊天谜案 / 震惊世界的失踪事件 / 至今无人能解

## 三、视觉双轨

封面和内页是两套刻意反差的风格，不要统一：

- **封面**：暗黑做旧、老照片贴档案板、胶带、大字钩子 —— 负责抢点击
- **内页**：白底极简、大量留白、克制的冰蓝点缀 —— 负责建立可信度

反差本身就是可信度设计：先用悬疑感把人拉进来，再用严肃档案感让人相信。

## 四、八页结构

```
P1 cover         封面钩子
P2 coordinate    时间 · 地点 · 一句话事件
P3 fact          反常事实之一
P4 fact          反常事实之二
P5 fact          诡异峰值
P6 contradiction 逻辑空洞          ← 命门
P7 official      官方结论与留白
P8 cta           互动引导 + 预告下期 CASE
```

P8 一定要预告下一期的 CASE 编号。双编号（CASE + ISSUE）制造的是追更心理，
这是把单条爆款转成账号资产的唯一手段。

## 五、一次内容，三个平台

PNG 序列是中间产物，三个平台的成品都从它派生：

| 平台 | 形态 | 说明 |
|---|---|---|
| 视频号 / 抖音 / 快手 | 9:16 翻页视频 | 主阵地，吃创作分成 |
| 小红书 | 图文轮播 | 零额外成本，PNG 直接用 |
| 公众号 | 纵向长图 + 正文 | **后期真正的变现主阵地**，别漏 |

## 六、节奏与数据

- 每页停留 4.2 秒，封面 3 秒，总时长约 30 秒 —— 短是为了完播率
- 连续做灾难题材会让账号情绪单调，每 5-6 期插一期「全员生还」类反转期
  （选题池里的坚忍号、罗戈佐夫自我手术就是为此准备的）
- 判断一期是否成立，看完播率而不是点赞；点赞高完播低说明钩子好但内容撑不住
- 前 30 期是打样期，不要指望数据，要指望把模板和流程跑顺

## 七、人工校订是流程的一部分

`write` 与 `build` 被刻意拆成两步，中间那步不能省：

```
python cli.py write --topic "..." --case-no N
# → 核对 script.json 里每一句：有没有推测句？数字对不对？钩子够不够具体？
python cli.py build --slug <slug>
```

模型会写出通顺但未经核实的句子，这是这类内容最大的翻车来源。
`script.json` 里的 `fact_notes` 就是给你核对用的底稿，不是装饰。
